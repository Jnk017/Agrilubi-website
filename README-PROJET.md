# Agropole du Sankuru — SALU

Site institutionnel en développement pour présenter le projet de la Société Agricole de Lubi, dans le Sankuru (RDC).

## Démarrer

```bash
npm install
npm run typecheck
npm run dev
```

## État
La branche `feat/institutional-foundation` constitue un premier import sécurisé, non exhaustif de la V0.5. Les documents juridiques internes et photographies non validées ne sont pas publiés. Les tests CI et Lighthouse doivent encore être vérifiés.
